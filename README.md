# EraaSoft Landing Page

A one page travel landing page: navbar, hero, services cards, a tabs section, an FAQ accordion and a footer. Most of the text is still lorem ipsum.

## Features

- Sticky navbar that gets a shadow when you scroll
- Elements fade in when you scroll to them (IntersectionObserver)
- Tabs (Offers / Suggestions / Reviews)
- Accordion for the questions
- Tilt effect on the service cards
- Works on mobile

## Built with

HTML, CSS and plain JavaScript. No libraries.

## How to run

Open `index.html` in your browser.
